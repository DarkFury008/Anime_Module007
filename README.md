# AnimePahe custom Shirox module

Experimental first pass based on the Sora module functions shown in the documentation.

## Files
- `module.json` — module manifest
- `animepahe.js` — async module functions

## Manifest URL after files are uploaded
`https://raw.githubusercontent.com/DarkFury008/Anime_Module007/main/module.json`

## Important
This has not been verified against the current AnimePahe site or inside Shirox. AnimePahe's domain, endpoints, anti-bot protection, and video host formats can change. A successful manifest import would not prove that search or playback works; test those separately and report the exact error/result.
